# Preponderous Software

Modular simulation systems and open-source software for complex environments,
ecosystems and emergent behavior.

- Website: https://preponderous.org
- Roam: https://roam.preponderous.org

## Notable repositories

**Games and simulations**

- [roam](https://github.com/Preponderous-Software/roam) — explore a procedurally generated 2D world and interact with its surroundings.
- [beyond-nations](https://github.com/Preponderous-Software/beyond-nations) — a sandbox nation-simulation RPG.
- [barony](https://github.com/Preponderous-Software/barony) — command armies to capture villages and castles against an AI opponent.
- [microbiome](https://github.com/Preponderous-Software/microbiome) — observe the activity of a virtual microbial community.
- [artificial-consciousness-simulation-framework](https://github.com/Preponderous-Software/artificial-consciousness-simulation-framework) — an experimental framework for simulating emergent properties of consciousness in an autonomous agent.

**Libraries and services**

- [viron](https://github.com/Preponderous-Software/viron) — a REST service for managing environments, grids, locations and entities.
- [py_env_lib](https://github.com/Preponderous-Software/py_env_lib) and [env-lib-cpp](https://github.com/Preponderous-Software/env-lib-cpp) — base classes for two-dimensional virtual worlds in Python and C++.
- [patchwork](https://github.com/Preponderous-Software/patchwork) — a lightweight Python tool for visualizing 2D environments.

**Websites**

- [preponderous-dot-org](https://github.com/Preponderous-Software/preponderous-dot-org) — the Preponderous Software website.
- [roam-website](https://github.com/Preponderous-Software/roam-website) — the Roam website.

The full list is under [Repositories](https://github.com/orgs/Preponderous-Software/repositories).
